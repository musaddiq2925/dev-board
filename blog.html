What are the different ways to select an element in the DOM?

  • getElementById
  • getElementsByClassName
  • getElementsByTagName
  • querySelector
  • querySelectorAll

What is the difference between innerHTML, innerText, and textContent?

  • HTML → innerHTML
  • Screen a text → innerText
  • all text → textContent

What is event delegation in the DOM??

  • Event Delegation is a technique in JavaScript where we add one event listener to a parent element instead of adding separate event listeners to each child element.

What is event delegation in the DOM?

  • Event Bubbling is a process in the DOM where an event starts from the target (child) element and then moves upward to its parent elements.

How do you create, add, and remove elements using JavaScript?

  • Create → createElement()
  • Add → append() / appendChild()
  • Remove → remove() / removeChild()
